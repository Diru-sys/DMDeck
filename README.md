# DMDeck

Aplicación web para Dungeon Masters: gestión de campañas, mapas,
audio ambiental, tracker de combate, dados y notas, todo en un solo lugar.

> TFG del ciclo de Desarrollo de Aplicaciones Web (DAW).

## Estado del proyecto
TBA

## Requisitos del proyecto
- RF-01 [MUST] Gestión de usuarios
- RF-02 [MUST] Campañas
- RF-03 [SHOULD] Mapas
- RF-04 [SHOULD] Soundboard y música
- RF-05 [SHOULD] Tiradas de dados animadas
- RF-06 [MUST] Tracker de combate
- RF-07 [MUST] Notas de campaña
- RF-08 [MUST] Enlaces de consulta

## Requisitos no funcionales
