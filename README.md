# Proyecto DnD

Aplicación web para Dungeon Masters: gestión de campañas, mapas,
audio ambiental, tracker de combate, dados y notas, todo en un solo lugar.

> TFG del ciclo de Desarrollo de Aplicaciones Web (DAW).

- `database/`: esquema de la base de datos
- `frontend/`: interfaz web
- `docs/`: memoria, diagramas y capturas
